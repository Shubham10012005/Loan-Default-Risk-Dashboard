# Loan Default Risk Dashboard

## 📌 Project Overview

The Loan Default Risk Dashboard is an end-to-end Data Analytics project that analyzes customer and loan data to identify patterns associated with loan defaults.

The project uses MySQL for data cleaning and analysis and Power BI for interactive visualization and dashboard development.

The objective is to help financial institutions understand loan risk patterns and identify customer segments with higher observed default rates.

## 🎯 Business Objective

The main objectives of this project are:

- Analyze the overall loan default rate
- Identify loan categories with higher observed default rates
- Understand the relationship between income and loan defaults
- Analyze default rates across loan amounts and interest rates
- Examine customer characteristics such as age, employment length, and home ownership
- Build an interactive Power BI dashboard for risk analysis
- Generate data-driven business insights
